## Why Linux

I want my everyday tools to be something I can read, change and understand. Linux makes that possible, and Omarchy, an opinionated setup, is the one I'm exploring right now.

## First commands I keep coming back to

```bash
# which system am I on?
cat /etc/os-release

# which kernel is running?
uname -r

# what is using my disk?
df -h
```

## Experiments

- Living in the terminal for a full week
- Moving my editor and shell configuration into plain-text dotfiles
- Learning the keyboard shortcuts of a tiling window manager

## What I'm noticing

Small friction points turn into small projects. Every fix becomes a note, and every note becomes a future entry.
